# users/

One YAML file per SFTP user. The filename must match the `username` inside it.

Full schema, every option and worked examples:
[`../../../modules/users-from-yaml/README.md`](../../../modules/users-from-yaml/README.md)

The three files here are illustrative - replace them with your real partners. Note that
`globex.yaml` carries a placeholder public key and an RFC 5737 documentation CIDR, so it
cannot actually be used as-is.
